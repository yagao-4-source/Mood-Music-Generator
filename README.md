# Mood Music Generator 🎵

## About
Mood Music Generator is a Python music project created using TunePad. It creates three different musical moods:

- **Happy:** Upbeat piano, drums and bass.
- **Sad:** Slow, emotional piano music.
- **Relaxed:** Calm piano with soft accompaniment.

## How to Use
1. Open the project in [TunePad](https://tunepad.com/project/134424), or import the JSON file from this repository.
2. Find the `mood_selector` code cell.
3. Change `selected_mood` to `"happy"`, `"sad"`, or `"relaxed"`.
4. Run the project to play the selected music. Save and refresh if needed.

## Project Files
- **JSON:** Complete TunePad project and Python code.
- **MP3:** Audio examples of the three moods.

**Created with:** TunePad and Python.
